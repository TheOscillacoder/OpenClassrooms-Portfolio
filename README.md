# OpenClassrooms-Portfolio
Créez et publiez votre portfolio de développeur


Portfolio développeur web de Guillaume Caro réalisé dans le cadre de la formation OpenClassrooms.

🔗 **Site en ligne : https://openclassrooms-portfolio.vercel.app/**

## Technologies
React, Vite, SCSS, Web3Forms (formulaire de contact)

## Lancer le projet en local
    cd .\frontend\
    npm install
    npm run dev


## Variables d'environnement :
- formulaire de contact avec clé Web3Forms

Créez un fichier `.env` dans `frontend/` :

    VITE_WEB3FORMS_KEY=valeur-VITE_WEB3FORMS_KEY
